# Waveshare ESP32-S3-AUDIO-Board

ESP32-S3 (16 MB flash, octal PSRAM) with an ES8311 DAC + speaker amplifier, ES7210 dual-mic ADC, TCA9555 I/O expander, three front buttons and a 7-LED WS2812 ring. Used as a Home Assistant voice satellite (micro wake word + voice assistant + media player with announcements, timers and an LED status ring).

- [Product page](https://www.waveshare.com/esp32-s3-audio-board.htm)
