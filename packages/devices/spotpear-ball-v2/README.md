# Spotpear ESP32-S3 AI Ball v2

Round 240x240 GC9A01A display, ES8311 codec, CST816 touch and a battery. Config is taken from [RealDeco/xiaozhi-esphome](https://github.com/RealDeco/xiaozhi-esphome/blob/main/devices/Spotpear%20Balls/Ball_v2.yaml) and adapted to use `packages/base.yaml`.

Character images and startup sound are selected with the `imagemodel` and `startup_sound` substitutions.

Hold the button to the left of the USB port to enable flashing mode.
