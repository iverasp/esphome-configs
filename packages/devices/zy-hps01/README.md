# Tuya ZY-HPS01 Presence sensor

My module had a CB3S module on it.

## Initial flashing

I was unable to program the module by connecting to the UART pins while it was soldered to the PCB. These are connected to the radar module through some resistors, which might have been the reason.

After desoldering the CB3S using a hot plate I was able to make a connection and upload the firmware.

OTA updates works fine.
