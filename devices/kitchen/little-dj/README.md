# little-dj

A RFC reader that controls whats playing on a speaker using Music Assistant.

Designed to be used by a toddler and mounted on his play kitchen.

RFC code ported from https://github.com/marcboon/RFIDuino/tree/master/SL018

## Hardware

- ESP32 devkit
- SL018 RFID reader
- 3d-printed cardholder and enclosure
